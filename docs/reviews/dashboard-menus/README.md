# Dashboard menu review

The screenshots use a local dashboard signed in as Participant 01. The inventory, groups and deployment attempts are fictional. The fixture renders the patched page components and substitutes local data for authentication and Intune. No deployment or tenant write is part of the walkthrough.

| Menu or page | Change to review |
| --- | --- |
| Primary navigation | Apps stays highlighted in Inventory, App catalog and Discovered apps. Activity stays highlighted in Deployments and Reports. On phones the navigation dialog keeps focus until it closes. |
| Account | The expanded and collapsed account buttons announce the account. The Settings link identifies the current location. Light, Dark and Same as computer retain their existing behavior. |
| Page and guide search | The header opens the palette at both screen widths. The input describes its actual destinations. New version checks links to the last check. App-specific links appear in the app workspace. |
| Home | Pending and Failed links keep the selected personal or tenant scope. The per-user table hides empty column headings. |
| Inventory | Four counts stay beside their labels. Publisher uses a native selector. Sort and view buttons identify the current selection. |
| Group changes | Expand an app to compare changed assignments and mark that revision reviewed. Missing copies and copies without install assignments have separate disclosures. A failed name lookup is distinguished from a confirmed missing group. |
| App details and workspace | The drawer distinguishes absent assignment data from an empty assignment list. Intune terms have explanations. The workspace labels the tenant update policy and keeps current release settings and future settings separate. |
| App updates | More actions has a larger phone target. Filter, sort, policy and scope menus expose their selection. Install dates and Open app workspace retain their destinations. A direct link to unsupported startup reports explains what happened. |
| Activity | Deployment status counts appear once, on the filters. Tenant and personal scope buttons announce the selected scope. Incomplete metadata no longer leaves empty separators. |
| Reports | Date presets use the theme accent and announce selection. An empty failure list avoids claiming all deployments succeeded. CSV export reports a failed request. |
| Discovered apps | The introductory guide starts closed and remembers an explicit choice. Sort controls expose the selected field and next direction. |
| App catalog | Global search and catalog search have separate shortcuts. Sort and category controls announce their selection. Curated apps uses the App catalog name on its return link. |
| Settings | General, Permissions and Notifications fit a phone and announce the selected section. General identifies the signed-in tenant and reports whether copying its ID succeeded. Notifications reports failed loads, labels webhook actions by name and keeps keyboard focus inside the form. |
| Help | The guides, illustrated controls and reference match the menu names, group review, discovery, scopes and tenant policy. All existing guide IDs are preserved. |
